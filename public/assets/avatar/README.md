# AgentiQ hyperrealistic 3D avatar

Place the final rigged GLB at:

`public/assets/avatar/agenticuantico-woman.glb`

Requirements:
- GLB / glTF 2.0
- humanoid rig preferred
- facial blendshapes / morph targets for blink and mouth/visemes preferred
- PBR materials
- 1K–2K textures for web performance
- original character design based on the supplied visual references, not a direct copy

The WebGPU avatar loader automatically detects this file and replaces the procedural fallback.
