# Background reference

The cinematic landing scene is prepared to use the user's Pinterest reference as a local asset:

`public/assets/background/pinterest-5dDqTJNiq.webp`

The site intentionally does not hotlink Pinterest media. Export/download the reference image you have permission to use, convert it to WebP, and place it at that exact path. Until the asset exists, the existing cinematic video remains visible as a subtle secondary layer.

Recommended: 1920x1080 or larger, WebP/AVIF, under ~2 MB for fast mobile loading.
