Cómo funciona

El chat envía la conversación al endpoint público del Neural Core. El Worker prioriza el motor configurado de Hugging Face y conserva un fallback de Cloudflare Workers AI. Los archivos se preparan en el navegador y se envían con límites. El modo “Pensar más” solicita razonamiento avanzado al motor sin exponer su cadena interna.

La voz natural se mantiene del lado servidor: cuando ElevenLabs está configurado, el Worker utiliza su API y nunca expone la clave al navegador. La interfaz ofrece perfiles por idioma y género, y el modo llamada encadena reconocimiento de voz → IA → voz para una experiencia manos libres.
