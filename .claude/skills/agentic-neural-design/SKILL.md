# AgentiCuantico Neural Design

Before changing UI:
- inspect the current DOM and runtime;
- read design-system/agenti-cuanti-co/MASTER.md;
- preserve existing application contracts;
- use the UI/UX Pro Max skill if it is installed in Claude Code.

Design goals:
- immersive neural 3D core;
- conversational-first UX;
- restrained glass/depth;
- responsive mobile;
- accessible focus and reduced motion;
- no fake functionality.

For Three.js/WebGL work, keep a graceful Canvas/CSS fallback and avoid unnecessary dependencies.
